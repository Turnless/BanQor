The worst case is small. An agent key can't touch the BTC or call owner functions. If one leaks, the most it can take is:

float it holds+rest of today's cap=≤ 2 + 20 MUSD

With the demo policy, until the owner presses pause. Then every draw reverts.

How it works

From BTC to a paid API call.Five steps, one of them yours.

1 · owner

Open a line

Deposit BTC. The vault opens a Mezo trove in its own name and keeps the minted MUSD.

2 · owner

Set the rules

Per agent: daily cap, max float, max single draw, expiry. Plus an ICR floor for the trove.

3 · agent

Draw just in time

When its float runs low the SDK calls draw(). If the vault is short, it borrows against the BTC.

4 · agent

Pay per request

The agent pays x402 APIs in MUSD with a signed permit. No gas, no custom protocol.

5 · owner

Stay in control

Pause, change rules, repay, add BTC or close. Anyone can rebalance a trove near its floor.

For agent developers, explained for everyone

Swap one line.Your agent can pay.

  1. 1

    Bring in BanQor

    Your AI agent adds the BanQor helper. That's the only new piece it needs.

    One import from @banqor/sdk.

  2. 2

    Connect it to your credit line

    The agent gets its own key and is pointed at your vault, the credit line backed by your Bitcoin on Mezo.

    Agent key, vault address, network and RPC.

  3. 3

    Keep a little pocket money

    When the agent has less than 0.20 MUSD on hand, it borrows 1 more from your vault by itself. Nobody tops it up.

    minFloat and topUp drive automatic draw() calls.

  4. 4

    Set a price limit

    Anything that costs more than 0.10 MUSD is refused before any money moves. Your own on-chain caps still apply on top.

    maxPricePerCall, checked before signing. Refusals come back as typed errors.

  5. 5

    Use the internet as usual

    The agent asks an API for data. If the API wants to be paid, the agent pays it in MUSD and gets the answer. No forms, no cards.

    A fetch-compatible function that handles x402 payments.

agent.ts
import { createBanQorFetch } from "@banqor/sdk";const fetchPaid = createBanQorFetch({  agentKey: process.env.AGENT_KEY,  vault: "0xcDa3Cb64aEd90C2A77981434d66AD3F3197fC791",  network: "eip155:31611",  rpcUrl: "https://rpc.test.mezo.org",  minFloat: "0.20",        // draw below this  topUp: "1.00",           // MUSD per draw  maxPricePerCall: "0.10",  // refuse pricier calls});const res = await fetchPaid("https://api.example.com/price");
